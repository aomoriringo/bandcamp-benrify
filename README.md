# Bandcamp Benrify

Bandcamp を便利に聴くための Windows アプリです。

- **キューイング**: 曲 / アルバム / レーベル・アーティストの URL を貼るだけで、その曲・アルバムの全曲・レーベルの全作品の全曲をキューに追加
- **ランダム再生**: キュー全体をシャッフル再生 (一周するまで同じ曲は流れません)。キーボードのメディアキーや Windows のメディアコントロールにも対応
- **サポーター数ランキング**: レーベル / アーティストの作品を、購入者 (サポーター) が多い順に並べて表示
- **Chrome 拡張 (任意)**: Bandcamp のページ上で右クリック → 「Benrify のキューに追加」

## Bandcamp への負荷について

Bandcamp に過剰なリクエストを送らないことを最優先にしています。

| 対策 | 内容 |
| --- | --- |
| 直列化 | Bandcamp へのリクエストはアプリ全体で 1 本のキューを通り、**同時に 1 件しか送りません** |
| 間隔 | リクエストの開始間隔は既定 **2.5 秒** (+ 0〜0.5 秒のゆらぎ)。設定で 1 秒未満にはできません |
| 制限応答への対応 | 429 / 503 を受けたら `Retry-After` に従って全体を停止し、以後の間隔を 1.5 倍に広げます (最大 15 秒) |
| キャッシュ | 解析結果をディスクに保存し、作品ページは 72 時間・作品一覧は 12 時間は再取得しません |
| 再生時 | 曲の再生に必要なのはストリーム URL だけで、期限 (約 1 日) が切れているときだけページを取り直します |
| 優先度 | 再生直前の取得は、ランキング集計などのバックグラウンド取得より先に処理します |
| User-Agent | `BandcampBenrify/x.y.z (+リポジトリURL)` を名乗ります |

画面右下に「待ち件数 / 累計リクエスト数 / 現在の間隔」が常に表示されます。

> レーベル全体を扱う操作は作品数ぶんのページ取得が必要です (例: 400 作品なら約 20 分)。
> 一度取得した作品はキャッシュされるので、ランキングとキュー追加で同じページを二度取りに行くことはありません。

## 使い方

1. 上の欄に Bandcamp の URL を貼り付けます
   - `https://xxx.bandcamp.com/track/...` → その曲
   - `https://xxx.bandcamp.com/album/...` → アルバムの全曲
   - `https://xxx.bandcamp.com/` や `/music` → レーベル / アーティストの全作品の全曲
2. **キューに追加** (Enter) でキューへ、**サポーター数ランキング** でランキングタブへ
3. 再生ボタンで再生。🔀 がオンならキュー全体からランダムに再生します

### キュー

- ダブルクリックでその曲を再生、Delete キーで削除、右クリックで「Bandcamp で開く」
- 既にキューにある曲は重複して追加されません
- キューはアプリを閉じても保存されます

### ショートカット

| キー | 動作 |
| --- | --- |
| Enter (URL 欄) | キューに追加 |
| Ctrl + Space | 再生 / 一時停止 |
| Ctrl + → / ← | 次へ / 前へ |
| メディアキー | 再生 / 一時停止 / 次へ / 前へ |

### サポーター数ランキング

- 「順位」「サポーター」列はサポーター数の多い順。列ヘッダーをクリックすると他の列でも並べ替えられます
- 作品ページに埋め込まれているサポーター (購入したファン) を数えます。Bandcamp のページには最大 80 人程度しか載らないため、それ以上いる作品は **「86+」** のように表示されます
- 「N+」の作品は **正確な人数を数える** (実験的) で、Bandcamp の「もっと見る」と同じ方法で追加取得して数えられます。1 作品あたり最大 30 リクエスト (= 約 3,000 人) までで、それを超える作品は「N+」のままです。行を選択していれば選択した作品だけを数えます
- 「試聴不可」は Bandcamp 上で音源が公開されていない作品 (グッズのみ等) です
- 行をダブルクリック / 「選択をキューに追加」でその作品の曲をキューへ

## Chrome 拡張のインストール (任意)

1. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにする
2. **パッケージ化されていない拡張機能を読み込む** で、このリポジトリの `extension` フォルダを選ぶ
3. Bandcamp のページやリンクを右クリック → 「Benrify のキューに追加」 / 「Benrify でサポーター数ランキングを表示」
   ツールバーのアイコンからも同じ操作ができます

拡張はアプリが `http://localhost:47823` で待ち受けている API に URL を渡すだけです。Bandcamp への取得はアプリ側が上記のルールで行います。
この API は localhost のみで、カスタムヘッダー必須・一般の Web ページからの要求は拒否します。

## ビルド

必要なもの: Windows 10 (19041) 以降、[.NET 10 SDK](https://dotnet.microsoft.com/download)

```powershell
dotnet run --project src/BandcampBenrify     # 起動
dotnet test                                   # テスト
.\publish.ps1                                 # 配布用の単体 exe (publish\BandcampBenrify.exe)
```

GitHub Actions でも push ごとにテストと単体 exe のビルドを行い、成果物 (Artifacts) としてダウンロードできます。

## 設定

`%APPDATA%\BandcampBenrify\settings.json` (初回終了時に作成されます)

| キー | 既定値 | 内容 |
| --- | --- | --- |
| `RequestIntervalSeconds` | 2.5 | リクエスト間隔 (秒)。1 未満は 1 になります |
| `PageCacheHours` | 72 | 作品ページのキャッシュ時間 |
| `DiscographyCacheHours` | 12 | 作品一覧のキャッシュ時間 |
| `ExactCountMaxRequestsPerItem` | 30 | 正確な人数を数えるときの 1 作品あたりの上限 |
| `LocalApiPort` | 47823 | Chrome 拡張用ポート。0 で無効 |

キャッシュは `%LOCALAPPDATA%\BandcampBenrify\cache` にあり、フォルダごと消しても問題ありません。

## 構成

```
src/BandcampBenrify.Core   取得・解析・キャッシュ・スロットリング・再生順 (UI 非依存、テストあり)
src/BandcampBenrify        WPF アプリ (再生は Windows.Media.Playback)
tests/                     xUnit テスト
extension/                 Chrome 拡張 (Manifest V3)
```

## 注意

- 再生するのは Bandcamp が試聴用に公開している 128kbps のストリームです。気に入った作品はぜひ Bandcamp で購入してアーティストを支援してください
- 非公式ツールです。Bandcamp のページ構造が変わると動かなくなることがあります
