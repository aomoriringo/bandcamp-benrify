# Bandcamp Benrify

Bandcamp を便利に聴くための Windows アプリです。

- **探す**: レーベル / アーティストの作品一覧から作品を選び、曲目を見て、試聴しながら曲やアルバムを選んでキューに追加
- **キューイング**: URL を貼るだけで、その曲・アルバムの全曲・レーベルの全作品の全曲をまとめてキューに追加することもできます
- **サポーター数で並べて聴く**: キューを「サポーター数 (アルバム購入 + 曲単体購入)」「値段」「リリース日」などで並び替え、上から順に再生
- **ランダム再生 / 1 曲リピート**: キュー全体をシャッフル (一周するまで同じ曲は流れません)。キーボードのメディアキーや Windows のメディアコントロールにも対応
- **購入済みマーク**: 自分の Bandcamp コレクションを読み込んで、購入済みの曲・作品に印 (アルバムで購入 / 曲で購入) を付ける・隠す
- **チェック済み**: 曲に自分用の印を付けて、一覧や再生から外せる (このアプリにだけ記録。キューから消しても残る)
- **値段**: 曲単体とアルバムのデジタル版の値段 (最低価格) を表示
- **波形と BPM**: 再生中の曲の波形をシークバーに表示し、BPM を推定する (一度再生した曲はキューの一覧にも BPM が出る)
- **ビジュアライザ**: ジャケットを大きく出し、周りの輪が音に合わせて動く画面を別ウィンドウ / 全画面で表示
- **Chrome 拡張 (任意)**: Bandcamp のページ上で右クリック → 「Benrify の「探す」で開く」「Benrify のキューに追加」

## ダウンロードして使う

[Releases](https://github.com/aomoriringo/bandcamp-benrify/releases/latest) から **BandcampBenrify.exe** をダウンロードして、そのまま実行してください。インストールや .NET の準備は要りません (Windows 10 (19041) 以降、64 ビット)。

- 初めて実行するとき「Windows によって PC が保護されました」と出ることがあります (署名していないため)。「詳細情報」→「実行」で起動できます
- 設定・キュー・キャッシュは `%LOCALAPPDATA%\BandcampBenrify` に保存されます。新しい版にするときは exe を置き換えるだけで、そのまま引き継がれます
- Chrome 拡張を使う場合は、同じページの **BandcampBenrify-chrome-extension.zip** を展開して、[Chrome 拡張のインストール](#chrome-拡張のインストール-任意) の手順で読み込みます

## ソースからインストール

[.NET 10 SDK](https://dotnet.microsoft.com/download) を入れた Windows 10 (19041) 以降で、リポジトリのフォルダで次を実行します (管理者権限は不要)。

```powershell
pwsh -File install.ps1            # スタートメニューに登録
pwsh -File install.ps1 -Desktop   # デスクトップにもショートカットを作る
```

- アプリは `%LOCALAPPDATA%\Programs\BandcampBenrify` に入り、スタートメニューで「Bandcamp」と検索して起動できます
- 更新するときも同じコマンドを実行します (アプリを終了してから。設定・キュー・キャッシュはそのまま)
- 取り除くときは `pwsh -File uninstall.ps1` (設定などのデータも消すなら `-RemoveData`)

## Bandcamp への負荷について

Bandcamp に過剰なリクエストを送らないことを最優先にしています。

| 対策 | 内容 |
| --- | --- |
| 直列化 | Bandcamp へのリクエストはアプリ全体で 1 本のキューを通り、**同時に 1 件しか送りません** |
| 間隔 | リクエストの開始間隔は既定 **5 秒** (+ 0〜0.5 秒のゆらぎ)。設定で変えられますが 1 秒未満にはできません |
| 制限応答への対応 | 429 / 503 を受けたら `Retry-After` に従って全体を停止し、以後の間隔を 1.5 倍に広げます (最大 15 秒) |
| アクセス確認 | ボット対策の確認ページが返ってきたら回避はせず、その取得を諦めて以後の間隔を広げます |
| キャッシュ | 解析結果をディスクに保存し、作品・曲ページは 72 時間、作品一覧は 12 時間は再取得しません |
| 必要な分だけ | 曲単体の情報 (1 曲 1 リクエスト) やサポーターの正確な人数は自動では取りに行かず、ボタンを押したときに未取得の分だけ取得します。1 作品あたりの上限があり、合計が多いとき (300 回以上) は実行前に確認します |
| 再生時 | 再生に必要なストリーム URL はキャッシュから使い、期限 (約 1 日) が切れているときだけページを取り直します |
| 波形・BPM | 再生のためにダウンロードした音声をそのまま解析します (解析のための追加のダウンロードはしません)。再生していない曲は解析しません。音声はメモリに置くだけで保存せず、解析結果 (波形と BPM) だけを残します |
| コレクション | 初回だけ全件読み込み (Bandcamp の API が 1 回 20 件まで)。以後は新しく買った分だけ読みます |
| 優先度 | 再生直前の取得は、バックグラウンドの取得より先に処理します |
| User-Agent | `BandcampBenrify/x.y.z` を名乗ります (ブラウザのふりはしません) |

画面右下に「待ち件数 / 累計リクエスト数 / 現在の間隔」が常に表示され、時間のかかる処理には残り時間の目安と「中止」ボタンが出ます。

## 使い方

### 探す (選んでキューに入れる)

1. 上の欄にレーベル / アーティスト / アルバム、またはファンのコレクション / ウィッシュリストの URL を貼り付けて Enter (または「探す」)
   - キーワードを入れた場合は、ブラウザで Bandcamp の検索ページを開きます (後述)
2. 左に作品一覧が出ます。作品を選ぶと右に曲目が出ます (未取得の作品は 1 リクエスト)
3. 曲目をダブルクリックで**試聴** (キューには入りません)。気に入った曲を選んで「選択した曲をキューに追加」、または「この作品の全曲をキューに追加」
   - 作品一覧も複数選択して右クリック →「選択した作品の全曲をキューに追加」ができます
   - 「作品の情報を取得」で一覧 (絞り込み後) の全作品のサポーター数・値段・リリース日を取得して並び替えられます (1 作品 1 リクエスト、所要時間の目安を表示)
   - サポーターが「N+」の作品は、続けて正確な人数を数えます (キューの「曲の情報を取得」と同じ方法・同じ上限)。サポーター数で並べて上から選び、Ctrl+Enter でまとめてキューに入れられます
   - 「絞り込み」でタイトル / アーティストを絞り込み、「購入済みを隠す」で買った作品を隠せます
   - 左上の ← で前の一覧に戻ります

**ほかの人のコレクション / ウィッシュリスト**: `https://bandcamp.com/ユーザー名` (コレクション) や `https://bandcamp.com/ユーザー名/wishlist` (ウィッシュリスト) も「探す」で開けます。
開いたときは最初の 20 件だけを読み込みます (1 リクエスト)。続きは「続きを読み込む」で 1 回 200 件 (10 リクエスト) ずつ読みます。何千件もある一覧を一度に読みに行かないためです。
読み込んだ分は作品一覧と同じ時間 (12 時間) 保存され、開き直しても続きから読めます。「キューに追加」には直接は入れられないので、「探す」で選んでから入れてください。

**キーワード検索について**: Bandcamp の検索ページにはアクセス確認 (ボット対策) があるため、アプリからは検索しません。
キーワードを入れるとブラウザで検索ページを開くので、気になるアーティストやアルバムの URL を貼るか、Chrome 拡張の右クリック「Benrify の「探す」で開く」で開いてください。

### まとめてキューに入れる

URL を貼って「キューに追加」(Ctrl+Enter) で、選ばずにそのままキューに入れます。

- `https://xxx.bandcamp.com/track/...` → その曲
- `https://xxx.bandcamp.com/album/...` → アルバムの全曲
- `https://xxx.bandcamp.com/` や `/music` → レーベル / アーティストの全作品の全曲 (400 作品なら約 20 分。取得済みの作品はすぐ)

### サポーター数で並べて上から聴く

1. 「**曲の情報を取得**」を押すと、表示中の全曲について次の 2 つを行います
   - 各曲のページを取得して、曲単体のサポーター数と値段を調べる (1 曲 1 リクエスト)
   - ページに載りきらず「N+」になっている作品のサポーターを、Bandcamp の「もっと見る」と同じ方法で**正確に数える** (100 人 1 リクエスト)
   - ボタンに未取得のページ数・人数が確定していない作品数と所要時間の目安が出ます。選んだ曲だけ取得するときは右クリック →「選択した曲の情報を取得」
2. 「**サポーター計**」の見出しをクリックすると多い順に並びます
3. ランダム再生 (🔀) をオフにすると、**表示されている順に上から**再生します

| 列 | 内容 |
| --- | --- |
| サポーター計 | アルバムのサポーター + 曲単体のサポーター。アルバムの中で単品買いが多い「その 1 曲」が上に来ます |
| うちアルバム / うち曲単体 | 内訳。単独リリースの曲はアルバムが「—」 |
| 曲の値段 / アルバムの値段 | デジタル版の値段 (最低価格)。「単品なし」は曲単体では買えない曲、「NYP」(Name Your Price) は 0 円から自分で値段を決められる |
| 購入済み | 「✓ アルバム」収録アルバムを購入済み / 「✓ 曲」曲を購入済み |
| レーベル | 作品を出しているレーベル (自主リリースは空欄)。古い版で取得した曲は「…」で、「曲の情報を取得」でアルバムページを取り直すと表示されます |

- 「45?」の「?」は曲単体が未取得 (アルバム分だけの数)、「86+」の「+」はまだ数えきれていない (Bandcamp のページには 80 人程度までしか載らないため、「曲の情報を取得」で続きを数えると消えます)
- 1 作品あたり 30 リクエスト (約 3,000 人) で一旦止めます。それより多い作品は「3080+」のように表示され、もう一度押すと続きから数えます (`settings.json` の `SupportersMaxRequestsPerItem` で変更可)
- 数えた結果は保存され、ページを取り直しても失われません (新しく買った人は加算されます)
- サポーター数は「アルバム / 曲のページに表示されるサポーター (購入したファン)」を数えたものです
- 「#」の列見出しをクリックすると、キューに追加した順に戻ります

### 購入済みマーク

1. 右上の「**設定**」で自分のプロフィール (`https://bandcamp.com/ユーザー名`) を入力して保存
2. コレクションが読み込まれ、キューの購入済みの曲に印が付きます。「購入済みを隠す」で一覧と再生対象から外せます

- 読めるのは**公開されている**コレクションだけです (非公開にした作品は判定できません)
- 初回は全件を読むので時間がかかります (Bandcamp の API は 1 回 20 件まで。7,000 件なら約 19 分)。途中で中止しても、次回の「コレクション更新」で続きから読み込みます
- 2 回目以降の「コレクション更新」は、新しく買った分だけを読みます (通常 1 リクエスト)

### チェック済み

「購入済み」とは別に、曲ごとに自分用の印を付けておけます (「もう聴いた」「買わないと決めた」など、使い方は自由です)。

- キューや「探す」の曲目の「**チェック**」列のチェックボックスをクリック、または選んだ曲を右クリック →「チェック済みにする」
- 再生中の曲は、プレイヤーの ✓ ボタン (**Ctrl+D**) で「チェックして次の曲へ」
- 「**チェック済みを隠す**」をオンにすると、キューの一覧と再生対象から外れます (「探す」では全曲チェック済みの作品を隠します)
- 「探す」の作品一覧の「チェック」列に、作品ごとのチェック済み曲数 (「2/4 曲」「✓ 全曲」) が出ます
- 記録は曲ごとに `%APPDATA%\BandcampBenrify\checked.json` に保存されます。キューとは別のファイルなので、**キューから削除 (「すべて削除」も含む) しても残ります**。あとで同じ曲をキューに入れたり「探す」で開いたりすると、印が付いた状態で出てきます。Bandcamp には何も送りません

### キューの操作

- ダブルクリック / Enter で再生、Delete キーで削除、右クリックで「Bandcamp で開く」など
- 既にキューにある曲は重複して追加されません
- キューはアプリを閉じても保存されます

### 波形と BPM

- 再生中の曲の波形がシークバーに表示されます (再生しながら左から描かれていき、数秒で全体がそろいます)。クリック・ドラッグでその位置へ移動できます
- BPM はダウンロードが終わったところで (再生開始から数秒後) 再生ボタンの並びの右端 (波形の右上) に出ます。曲から自動で推定した目安で、倍や半分になっていることがあります。テンポがはっきりしない曲は「—」です
- 一度再生した曲は、キューと「探す」の曲目の「BPM」列にも出ます (列で並び替えもできます)

### ビジュアライザ

- プレイヤーのジャケットをクリック (または音量の左のボタン / Ctrl+Shift+V) で、別ウィンドウで開きます
- ジャケットを大きく表示し、周りの輪が音域ごとの音量で伸び縮みします (上から時計回りに低音 → 高音)。輪の色はジャケットの色から始まり、再生中はゆっくり移り変わります (2 分で色相をひと回り)。曲名・アーティスト・レーベル・BPM・サポーター数・波形も出ます
- F11 かダブルクリックで全画面、Esc で全画面の解除 / 閉じる。2 台目のモニターに映したまま、メインの画面で操作を続けられます
- マウスを動かすと右上に操作ボタンが出ます。Space / Ctrl+→ / Ctrl+D などのショートカットもそのまま使えます
- ジャケットは丸く切り抜いて表示し、再生中はゆっくり回します (20 秒で 1 回転)
- 音は再生のためにダウンロードしたものを解析して使うので、Bandcamp へのリクエストは増えません (ジャケットを大きい画像で表示する分だけ、画像の読み込みが 1 回増えます)


### 見た目 (テーマカラー)

- 画面は暗い配色です。ボタン・タブ・再生中の曲などに使う「テーマカラー」を「設定」で選べます (水色・琥珀・ライム・ローズ・ラベンダー・ホワイト、または `#RRGGBB` で好きな色)。選ぶとすぐ反映され、キャンセルで元に戻ります
- 再生バーは、再生中の曲のジャケットの色に合わせて変わります (設定でオフにするとテーマカラー)。色は表示しているジャケット画像から取るので、Bandcamp へのリクエストは増えません。白黒のジャケットのときはテーマカラーを使います
- 「サポーター計」の横の棒は、キューの中での多さの目安です (多い方から 1 割に入る曲は最大の長さ)

### ショートカット

| キー | 動作 |
| --- | --- |
| Enter (URL 欄) | 探す |
| Ctrl + Enter (URL 欄) | そのままキューに追加 |
| Enter / Ctrl + Enter (探す の曲目) | 試聴 / キューに追加 |
| Ctrl + Space | 再生 / 一時停止 |
| Ctrl + → / ← | 次へ / 前へ |
| Ctrl + D | 再生中の曲をチェック済みにして次へ |
| Ctrl + M | 消音 / 解除 (音量アイコンのクリックでも) |
| Ctrl + Shift + V | ビジュアライザを開く |
| メディアキー | 再生 / 一時停止 / 次へ / 前へ |

## Chrome 拡張のインストール (任意)

1. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにする
2. **パッケージ化されていない拡張機能を読み込む** で、このリポジトリの `extension` フォルダ (Releases の zip を展開したフォルダ) を選ぶ
3. Bandcamp のページやリンク (検索結果を含む) を右クリック → 「Benrify の「探す」で開く」または「Benrify のキューに追加」 (ツールバーのアイコンからも可)

拡張はアプリが `http://localhost:47823` で待ち受けている API に URL を渡すだけです。Bandcamp への取得はアプリ側が上記のルールで行います。
この API は localhost のみで、カスタムヘッダー必須・一般の Web ページからの要求は拒否します。

## ビルド

必要なもの: Windows 10 (19041) 以降、[.NET 10 SDK](https://dotnet.microsoft.com/download)

```powershell
dotnet run --project src/BandcampBenrify     # 起動
dotnet test                                   # テスト
$env:BENRIFY_DATA_DIR = "$PWD\devdata"; dotnet run --project src/BandcampBenrify   # 普段使いのキュー・設定に触れずに試す
.\publish.ps1                                 # 配布用の単体 exe (publish\BandcampBenrify.exe)
```

GitHub Actions でも push ごとにテストと単体 exe のビルドを行い、成果物 (Artifacts) としてダウンロードできます。

### バージョン

[セマンティックバージョニング](https://semver.org/lang/ja/) (MAJOR.MINOR.PATCH) で付けます。まだ 1.0 前なので 0.x です。

- 番号は `Directory.Build.props` の `<Version>` だけで決まり、exe・User-Agent・設定画面の表示に使われます
- 機能を足したら MINOR (0.1.0 → 0.2.0)、不具合の修正だけなら PATCH (0.1.0 → 0.1.1) を上げます
- リリースするときは `v0.1.0` の形で git のタグを付けて push します。GitHub Actions がテスト・単体 exe のビルドをして Releases に載せます (タグと `<Version>` が違うと止まります)

## 設定とデータ

アプリの「設定」で、テーマカラー・プロフィール・リクエスト間隔の変更と、キャッシュの削除 (作品ページ・作品一覧・コレクション・曲の解析ごとに使用量を表示) ができます。

| 場所 | 内容 |
| --- | --- |
| `%APPDATA%\BandcampBenrify\settings.json` | 設定 (プロフィール、間隔、音量、ウィンドウ位置など) |
| `%APPDATA%\BandcampBenrify\queue.json` | キュー |
| `%APPDATA%\BandcampBenrify\checked.json` | チェック済みの曲 (キューを消しても残ります) |
| `%LOCALAPPDATA%\BandcampBenrify\cache` | 取得したページ・コレクションのキャッシュ (消しても問題ありませんが、取り直すぶん Bandcamp へのアクセスが増えます) |

キュー・チェック済み・設定は、一時ファイルに書いてから置き換えるので、保存中に PC が落ちても前回の内容が残ります。キューやチェック済みのファイルが読み込めなかったときは `queue.json.broken-日時` のような名前で残してから空の状態で始めるので、中身を確かめて元の名前に戻せば復元できます。

`settings.json` だけで設定できる項目: `PageCacheHours` (72)、`DiscographyCacheHours` (12)、`SupportersMaxRequestsPerItem` (30)、`LocalApiPort` (47823、0 で拡張用 API を無効)

## 構成

```
src/BandcampBenrify.Core   取得・解析・キャッシュ・スロットリング・集計・再生順 (UI 非依存、テストあり)
src/BandcampBenrify        WPF アプリ (再生は Windows.Media.Playback)
tests/                     xUnit テスト
extension/                 Chrome 拡張 (Manifest V3)
tools/make-icon.ps1        アプリのアイコン (Assets/app.ico) を作り直すスクリプト
install.ps1 / uninstall.ps1  スタートメニューへの登録 / 削除
```

## 注意

- 再生するのは Bandcamp が試聴用に公開している 128kbps のストリームです。気に入った作品はぜひ Bandcamp で購入してアーティストを支援してください
- 非公式ツールです。Bandcamp のページ構造が変わると動かなくなることがあります
