# Bandcamp Benrify

Bandcamp を便利に聴くための Windows アプリです。

- **探す**: レーベル / アーティストの作品一覧から作品を選び、曲目を見て、試聴しながら曲やアルバムを選んでキューに追加
- **キューイング**: URL を貼るだけで、その曲・アルバムの全曲・レーベルの全作品の全曲をまとめてキューに追加することもできます
- **サポーター数で並べて聴く**: キューを「サポーター数 (アルバム購入 + 曲単体購入)」「値段」「リリース日」などで並び替え、上から順に再生
- **ランダム再生 / 1 曲リピート**: キュー全体をシャッフル (一周するまで同じ曲は流れません)。キーボードのメディアキーや Windows のメディアコントロールにも対応
- **購入済みマーク**: 自分の Bandcamp コレクションを読み込んで、購入済みの曲・作品に印 (アルバムで購入 / 曲で購入) を付ける・隠す
- **値段**: 曲単体とアルバムのデジタル版の値段 (最低価格) を表示
- **Chrome 拡張 (任意)**: Bandcamp のページ上で右クリック → 「Benrify の「探す」で開く」「Benrify のキューに追加」

## Bandcamp への負荷について

Bandcamp に過剰なリクエストを送らないことを最優先にしています。

| 対策 | 内容 |
| --- | --- |
| 直列化 | Bandcamp へのリクエストはアプリ全体で 1 本のキューを通り、**同時に 1 件しか送りません** |
| 間隔 | リクエストの開始間隔は既定 **2.5 秒** (+ 0〜0.5 秒のゆらぎ)。設定で変えられますが 1 秒未満にはできません |
| 制限応答への対応 | 429 / 503 を受けたら `Retry-After` に従って全体を停止し、以後の間隔を 1.5 倍に広げます (最大 15 秒) |
| アクセス確認 | ボット対策の確認ページが返ってきたら回避はせず、その取得を諦めて以後の間隔を広げます |
| キャッシュ | 解析結果をディスクに保存し、作品・曲ページは 72 時間、作品一覧は 12 時間は再取得しません |
| 必要な分だけ | 曲単体の情報 (1 曲 1 リクエスト) は自動では取りに行かず、ボタンを押したときに未取得の分だけ取得します |
| 再生時 | 再生に必要なストリーム URL はキャッシュから使い、期限 (約 1 日) が切れているときだけページを取り直します |
| コレクション | 初回だけ全件読み込み (Bandcamp の API が 1 回 20 件まで)。以後は新しく買った分だけ読みます |
| 優先度 | 再生直前の取得は、バックグラウンドの取得より先に処理します |
| User-Agent | `BandcampBenrify/x.y.z (+リポジトリURL)` を名乗ります |

画面右下に「待ち件数 / 累計リクエスト数 / 現在の間隔」が常に表示され、時間のかかる処理には残り時間の目安と「中止」ボタンが出ます。

## 使い方

### 探す (選んでキューに入れる)

1. 上の欄にレーベル / アーティスト / アルバムの URL を貼り付けて Enter (または「探す」)
   - キーワードを入れた場合は、ブラウザで Bandcamp の検索ページを開きます (後述)
2. 左に作品一覧が出ます。作品を選ぶと右に曲目が出ます (未取得の作品は 1 リクエスト)
3. 曲目をダブルクリックで**試聴** (キューには入りません)。気に入った曲を選んで「選択した曲をキューに追加」、または「この作品の全曲をキューに追加」
   - 作品一覧も複数選択して右クリック →「選択した作品の全曲をキューに追加」ができます
   - 「作品の情報を取得」で一覧の全作品のサポーター数・値段・リリース日を取得して並び替えられます (1 作品 1 リクエスト、所要時間の目安を表示)
   - 「絞り込み」でタイトル / アーティストを絞り込み、「購入済みを隠す」で買った作品を隠せます
   - 左上の ← で前の一覧に戻ります

**キーワード検索について**: Bandcamp の検索ページにはアクセス確認 (ボット対策) があるため、アプリからは検索しません。
キーワードを入れるとブラウザで検索ページを開くので、気になるアーティストやアルバムの URL を貼るか、Chrome 拡張の右クリック「Benrify の「探す」で開く」で開いてください。

### まとめてキューに入れる

URL を貼って「キューに追加」(Ctrl+Enter) で、選ばずにそのままキューに入れます。

- `https://xxx.bandcamp.com/track/...` → その曲
- `https://xxx.bandcamp.com/album/...` → アルバムの全曲
- `https://xxx.bandcamp.com/` や `/music` → レーベル / アーティストの全作品の全曲 (400 作品なら約 20 分。取得済みの作品はすぐ)

### サポーター数で並べて上から聴く

1. 「**曲の情報を取得**」を押すと、各曲のページを取得して曲単体のサポーター数と値段を調べます
   - 1 曲 1 リクエストなので、ボタンに未取得のページ数と所要時間の目安が出ます。曲を選択していれば選択した曲だけ取得します
2. 「**サポーター計**」の見出しをクリックすると多い順に並びます
3. ランダム再生 (🔀) をオフにすると、**表示されている順に上から**再生します

| 列 | 内容 |
| --- | --- |
| サポーター計 | アルバムのサポーター + 曲単体のサポーター。アルバムの中で単品買いが多い「その 1 曲」が上に来ます |
| うちアルバム / うち曲単体 | 内訳。単独リリースの曲はアルバムが「—」 |
| 曲の値段 / アルバムの値段 | デジタル版の値段 (最低価格)。「単品なし」は曲単体では買えない曲、「自由価格」は 0 円から |
| 購入済み | 「✓ アルバム」収録アルバムを購入済み / 「✓ 曲」曲を購入済み |

- 「45?」の「?」は曲単体が未取得 (アルバム分だけの数)、「86+」の「+」はページに載りきらないほど多い (Bandcamp のページには 80 人程度までしか載らないため)
- サポーター数は「アルバム / 曲のページに表示されるサポーター (購入したファン)」を数えたものです
- 「追加順に戻す」で並び替えを解除できます

### 購入済みマーク

1. 右上の「**設定**」で自分のプロフィール (`https://bandcamp.com/ユーザー名`) を入力して保存
2. コレクションが読み込まれ、キューの購入済みの曲に印が付きます。「購入済みを隠す」で一覧と再生対象から外せます

- 読めるのは**公開されている**コレクションだけです (非公開にした作品は判定できません)
- 初回は全件を読むので時間がかかります (Bandcamp の API は 1 回 20 件まで。7,000 件なら約 19 分)。途中で中止しても、次回の「コレクション更新」で続きから読み込みます
- 2 回目以降の「コレクション更新」は、新しく買った分だけを読みます (通常 1 リクエスト)

### キューの操作

- ダブルクリック / Enter で再生、Delete キーで削除、右クリックで「Bandcamp で開く」など
- 既にキューにある曲は重複して追加されません
- キューはアプリを閉じても保存されます

### ショートカット

| キー | 動作 |
| --- | --- |
| Enter (URL 欄) | 探す |
| Ctrl + Enter (URL 欄) | そのままキューに追加 |
| Enter / Ctrl + Enter (探す の曲目) | 試聴 / キューに追加 |
| Ctrl + Space | 再生 / 一時停止 |
| Ctrl + → / ← | 次へ / 前へ |
| メディアキー | 再生 / 一時停止 / 次へ / 前へ |

## Chrome 拡張のインストール (任意)

1. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにする
2. **パッケージ化されていない拡張機能を読み込む** で、このリポジトリの `extension` フォルダを選ぶ
3. Bandcamp のページやリンク (検索結果を含む) を右クリック → 「Benrify の「探す」で開く」または「Benrify のキューに追加」 (ツールバーのアイコンからも可)

拡張はアプリが `http://localhost:47823` で待ち受けている API に URL を渡すだけです。Bandcamp への取得はアプリ側が上記のルールで行います。
この API は localhost のみで、カスタムヘッダー必須・一般の Web ページからの要求は拒否します。

## ビルド

必要なもの: Windows 10 (19041) 以降、[.NET 10 SDK](https://dotnet.microsoft.com/download)

```powershell
dotnet run --project src/BandcampBenrify     # 起動
dotnet test                                   # テスト
.\publish.ps1                                 # 配布用の単体 exe (publish\BandcampBenrify.exe)
```

GitHub Actions でも push ごとにテストと単体 exe のビルドを行い、成果物 (Artifacts) としてダウンロードできます。

## 設定とデータ

アプリの「設定」で、プロフィール・リクエスト間隔・キャッシュ削除ができます。

| 場所 | 内容 |
| --- | --- |
| `%APPDATA%\BandcampBenrify\settings.json` | 設定 (プロフィール、間隔、音量、ウィンドウ位置など) |
| `%APPDATA%\BandcampBenrify\queue.json` | キュー |
| `%LOCALAPPDATA%\BandcampBenrify\cache` | 取得したページ・コレクションのキャッシュ (消しても問題ありません) |

`settings.json` だけで設定できる項目: `PageCacheHours` (72)、`DiscographyCacheHours` (12)、`LocalApiPort` (47823、0 で拡張用 API を無効)

## 構成

```
src/BandcampBenrify.Core   取得・解析・キャッシュ・スロットリング・集計・再生順 (UI 非依存、テストあり)
src/BandcampBenrify        WPF アプリ (再生は Windows.Media.Playback)
tests/                     xUnit テスト
extension/                 Chrome 拡張 (Manifest V3)
```

## 注意

- 再生するのは Bandcamp が試聴用に公開している 128kbps のストリームです。気に入った作品はぜひ Bandcamp で購入してアーティストを支援してください
- 非公式ツールです。Bandcamp のページ構造が変わると動かなくなることがあります
